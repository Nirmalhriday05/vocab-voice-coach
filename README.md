# Vocab Voice Coach

A voice coach for workplace vocabulary, built as a prototype for Apna's Product Operations Associate application.

It teaches ten words people meet in their first weeks at a new job (punctual, deadline, onboarding, reliable and others). The coach reads each word and a real work situation aloud, and you answer with your own sentence, by voice or by typing. It checks the answer, reads back a model sentence, and brings missed words back for a second round. At the end you get a summary and a phrasebook of your own sentences.

The whole app works in English, Hindi or Kannada.

**Live demo:** https://nirmalhriday05.github.io/vocab-voice-coach/

Voice answers and recording playback need Chrome and microphone permission.

Built with plain HTML, CSS and JavaScript, using the browser's Web Speech API for speaking and listening. No server and no sign-up.
